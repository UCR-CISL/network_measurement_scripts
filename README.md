# Network measurement scripts
This repository is a collection of scripts for network measurement and analysis.

- `handshake.py`: Ping-pong handshake script to test the connectivity and IP address of two hosts.
- `rtt.py`: A `ping` like script to measure the round-trip time (RTT) between two hosts.
- `ftp.py`: A simple FTP client to upload and download files from an FTP server.
